# Концепция приложения

Приложение — это **Telegram-бот с командой ИИ-агентов для SMM**, который помогает бизнесу, бренду, эксперту или блогеру быстро получить стратегически обоснованные идеи и сценарии для коротких видео.

Пользователь отправляет в бот описание компании, продукта, ниши или блога. Система анализирует вводные данные, определяет целевую аудиторию, сегменты, боли, триггеры, позиционирование и контентные направления. После этого ИИ-агенты генерируют идеи для видео, проверяют их на качество, отбраковывают слабые и мусорные варианты, а затем создают готовые сценарии.

## Главная ценность

Приложение не просто генерирует случайные идеи для контента. Оно работает как **мини-SMM-стратег**, который сначала понимает аудиторию и бренд, а уже потом предлагает контент.

## Как работает приложение

```text
Описание компании / бренда / блога
↓
Анализ ЦА и сегментов
↓
Выявление болей, желаний и триггеров
↓
Позиционирование и контентная стратегия
↓
Генерация идей для видео
↓
Проверка и отбраковка слабых идей
↓
Создание сценариев
↓
Финальный контент-пак
```

## Что получает пользователь

В результате пользователь получает:

```text
- краткий анализ целевой аудитории;
- основные боли и триггеры аудитории;
- контентные направления;
- список качественно отобранных идей;
- готовые сценарии коротких видео;
- объяснение, почему идеи подходят;
- список отклоненных идей и причины отказа.
```

## Ключевая особенность

Внутри приложения есть не только агенты-генераторы, но и **агенты-критики**. Они проверяют идеи и сценарии по критериям:

```text
- попадание в ЦА;
- конкретность боли;
- связь с продуктом;
- потенциал удержания;
- отсутствие банальности;
- безопасность формулировок;
- пригодность для короткого видео.
```

Это снижает риск получить “мусорные” идеи вроде общих советов, шаблонных тем или контента без связи с продуктом.

## Формат MVP

MVP реализуется как Telegram-бот:

```text
Telegram Bot
↓
AI Agent Pipeline
↓
OpenRouter API
↓
PostgreSQL
```

На первом этапе приложение не требует сложного frontend, S3, аналитических систем или тяжелой инфраструктуры. Основной фокус — качество агентной логики и полезность финального контент-пака.

## Простое позиционирование

**Это AI SMM-ассистент, который превращает описание бизнеса в продуманные идеи и сценарии для коротких видео с автоматической проверкой качества.**
